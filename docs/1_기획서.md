## 과제명
**FitCoach — 운동·식단·체성분 기록이 한 권의 매거진처럼 쌓이는 AI 헬스 코칭 트래커**

- 팀원 및 역할: (작성 — 예: OOO 백엔드/AI, OOO 프론트엔드, OOO 기획/문서)

## 아이디어 주제
운동 프로그램 관리 + **AI 자세 분석(Form Check)** + 식단·체성분 기록을 하나로 묶은 통합 헬스 코칭 웹/PWA 앱. 매일의 기록이 "한 권의 매거진"처럼 쌓이는 에디토리얼 UX.

## 제안 배경 및 필요성
- 헬스 입문자는 ① 어떤 프로그램을 할지, ② 자세가 맞는지, ③ 식단·체성분이 어떻게 변하는지를 **각각 다른 앱**으로 관리해야 하는 불편이 있다.
- 특히 **자세(폼) 교정**은 PT 없이는 피드백받기 어렵다. 잘못된 자세는 부상·정체로 이어진다.
- FitCoach는 **프로그램 자동 증량 + 영상 기반 AI 자세 진단 + 식단/체성분 추이 + 코칭 코멘트**를 한 화면에서 제공해 "기록→피드백→개선" 루프를 완성한다.

## 시장 및 유사 제품 현황
| 구분 | 기존 서비스 | 한계 | FitCoach 차별점 |
|---|---|---|---|
| 프로그램 트래커 | Strong, FitNotes | 증량/프로그램 엔진 단순, 자세 피드백 없음 | 10종 프로그램 + 자동 증량 + 1RM 계산기 |
| 자세 분석 | 일부 PT앱/유료 | 비용 큼, 실시간만 | 영상 업로드/촬영 → 5축 자동 진단 |
| 식단 | MyFitnessPal | 매크로 위주, 코칭 약함 | 매크로 + AI 총평 + 체성분 연동 |

## 제안 내용 (핵심 기능)
1. **회원·프로필** — 가입 시 신체정보·목표 입력 → BMR/TDEE 자동 계산, 닉네임·아바타
2. **운동 프로그램** — StrongLifts 5×5·nSuns·5/3/1·Texas Method 등 10종, 성공 시 자동 증량, 1RM(Epley) 계산기
3. **Form Check (AI 자세 분석)** — 영상 업로드/가이드 촬영 → YOLO 크롭 + MediaPipe 포즈 추정 → **점수 기반 5축 진단**(안정성·가동범위·동작품질·자세·코어) 리포트
4. **식단(Meals)** — 끼니별 칼로리·탄수·단백·지방 기록(사진/검색/즐겨찾기), 목표 대비 진척, AI 총평
5. **체성분(Body/InBody)** — 체중·골격근·체지방·체지방률·기초대사량 기록, 추이 그래프, AI 코멘트
6. **저널(Journal)** — 달력 기반 일별 entry, 주간 리포트 + AI 총평
7. **커뮤니티(Personals)** — 운동 메이트 모집 글(1RM·위치), 댓글(비밀댓글)·좋아요

## 기반 연구 및 본인 기여 (Form Check)
- **기반 연구**: PSLeon24(고영민), GitHub `AI_Exercise_Pose_Feedback` / IEEE Access 2024 *"Real-time AI posture correction for powerlifting exercises using YOLOv5 and MediaPipe"* — YOLOv5 + MediaPipe + Random Forest로 파워리프팅 **3대 운동**(벤치프레스·스쿼트·데드리프트) 자세를 교정하는 연구. 원작 분류 정확도(RF): 스쿼트 98.9% · 벤치 96.1% · 데드 94.7%.
- **본인 기여**: 해당 모델을 **분석**한 뒤, 원작에 **없던 점수 기반(score-based) 평가 로직**을 직접 **설계·구현**했다(자세를 단순 정상/오류가 아닌 **정량 5축 점수**: 안정성·가동범위·동작품질·자세·코어로 환산). **이 점수 로직을 토대로 지원 운동을 18종으로 확장**하고, FastAPI 사이드카로 **서비스화**하여 웹/모바일과 통합했다.
- **운동 18종의 두 갈래(정직한 명시)**: ① **3대 운동**은 원작의 **학습된 RF 모델(.pkl)**을 사용(위 정확도). ② **추가 15종**(바벨컬·플랭크·런지·OHP·바벨로우·인클라인벤치·랫풀다운·사이드레터럴·머신플라이·스모데드·프론트레이즈·클로즈그립벤치·라잉트라이셉스·크런치·레그레이즈)은 **학습 모델이 아닌 관절 각도 규칙 + 점수 로직**으로 판정한다. 추가 운동용 **라벨링 데이터셋이 없어** 학습 대신 규칙 기반을 택했으며, 따라서 별도 분류 정확도 수치는 없다(향후 데이터 확보 시 동일 파이프라인에서 학습 모델로 교체 가능).
