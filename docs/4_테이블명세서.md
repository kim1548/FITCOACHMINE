# 테이블 명세서 — FitCoach (SQLite)

> 같은 폴더의 `4_테이블명세서.xlsx`(엑셀 버전)도 함께 생성됨. 양식 표에 옮겨 사용하세요.

## 11. formcheck_logs (폼체크 기록)
> AI 자세 분석(Form Check) 결과를 로그인 회원 계정에 1건씩 저장. Journal 일별 entry에서 그날의 운동·식단·체성분과 함께 노출된다. (오류 프레임 이미지는 용량 부담으로 저장하지 않고, 5축 점수·피드백·총평까지만 저장)

| 컬럼명 | 컬럼ID | 타입 | NN | 키 | 비고 |
|---|---|---|---|---|---|
| 아이디 | id | INTEGER | Y | PK | |
| 회원 | user_id | INTEGER | N | FK→users.id, IDX | |
| 분석일 | logged_date | DATE | N | IDX | Journal 일별 조인 키 |
| 운동종류 | exercise_type | VARCHAR | N | | 예: 스쿼트 |
| 점수 | score | FLOAT | N | | 종합 점수 0~100 |
| 횟수 | rep_count | INTEGER | N | | 반복 횟수 |
| 카테고리점수 | cat_scores | JSON | N | | 5축 점수 {"Stability":85,…} |
| 카테고리피드백 | cat_details | JSON | N | | 5축 피드백 문구 |
| 총평 | overall | TEXT | N | | 한 줄 총평 |
| 생성일시 | created_at | DATETIME | N | | 기본값 now |
