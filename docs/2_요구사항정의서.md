> **FR-07·08 기반 연구 및 본인 확장**: 폼체크 핵심 파이프라인은 PSLeon24(고영민)의 IEEE Access 2024 연구 *"Real-time AI posture correction for powerlifting exercises using YOLOv5 and MediaPipe"*(YOLOv5+MediaPipe+Random Forest, 3대 운동, 정확도 94.7~98.9%)를 **기반**으로 한다. 본인은 해당 모델을 **분석**해 원작에 **없던 점수 기반 평가 로직을 설계·구현**하였고, **그 점수 로직을 토대로 지원 운동을 18종으로 확장**한 뒤 FastAPI 사이드카로 **서비스화**했다.
>
> **판정 방식 2종(정직한 명시)**: ① **3대 운동**(벤치·스쿼트·데드)은 원작의 **학습된 RF 모델(.pkl)** 사용 → 위 정확도 적용. ② **추가 15종**은 **학습 모델이 아닌 관절 각도 규칙 + 점수 로직**으로 판정한다. 추가 운동용 라벨링 데이터셋이 없어 학습 대신 규칙 기반을 택했으며, **별도 분류 정확도 수치는 없다**(데이터 확보 시 동일 구조에서 학습 모델로 교체 가능).

## 2. 비기능 요구사항
- **성능**: 폼체크 영상 분석은 사이드카(8003)에서 처리, AI 총평은 Ollama 응답 대기(첫 호출 수십 초)
- **호환**: 반응형 웹 + PWA(모바일 홈 화면 설치), Chrome/Edge/Samsung Internet
- **보안**: 비밀번호 해시(bcrypt), JWT 토큰 인증, 비밀댓글 작성자/대상만 열람
- **확장성**: 메인 백엔드/AI 사이드카/LLM 분리 구조
