# FitCoach — 경쟁제품 · 기술 · 특허 분석 보고서

> 운동 프로그램 · AI 자세 분석(Form Check) · 식단 · 체성분 · 커뮤니티 통합 헬스 코칭 웹/PWA 프로젝트의
> 경쟁 환경(제품·기술·특허)을 분석한다.

---

## 1. 경쟁제품 분석

### 1.1 경쟁 구도
운동·자세·식단 영역의 서비스는 크게 **4개 경쟁 군**으로 형성되어 있으며, 대부분 1~2개 영역에 특화되어 있다.

| 경쟁 군 | 대표 제품 | 강점 | 빈틈(미구현) |
|---|---|---|---|
| AI 영상 폼체크 | Gym Score AI, Gymaholic | 영상 → 다축 점수화 성숙(1,800~2,500종) | 프로그램·식단·체성분·커뮤니티 없음 |
| 중량 프로그램 트래커 | Boostcamp(120만+), StrongLifts | 자동 증량 엔진·프로그램 라이브러리 | 폼체크·식단·체성분 없음 |
| 운동+식단 올인원 | GymStreak(400만+), MyFitnessCoach, 헬스매치 | 운동+식단+체성분+AI코치 통합 | 영상 폼체크 부재(3D 시연만), 커뮤니티 약함 |
| 식단·체성분·커뮤니티(국내) | 인아웃, 필라이즈, 밀리그램(170만 DL) | 식단 AI·체성분·커뮤니티 성숙 | 영상 폼체크·바벨 프로그램 엔진 없음 |

### 1.2 제품별 현황 요약
| 서비스 | 핵심 기능 | 운영 현황 |
|---|---|---|
| Gym Score AI | 영상→5개 카테고리 0~100점, 2,500+종, AI 코칭 챗·랭킹 | 운영 중 · 4.8★ · 무료 시작 |
| Gymaholic AI Form Checker | 영상 업로드→6개 범주 점수, 1,800+종 | 운영 중 · 사용자 8만+ · 구독 |
| Boostcamp | 프로그램 자동 증량, 1RM·PR·볼륨 추적 | 사용자 120만+ · 4.8★ · 무료+Pro |
| GymStreak | AI 루틴 + 식단 사진 인식 + 체성분 | 다운로드 400만+ · 4.7★ |
| MyFitnessCoach | 식단 사진 + 운동 프로그램 + 체성분 | 운영 중 · 규모 비공개 |
| HealthMatch(헬스매치) | AI 음식 스캔 + 운동 버디 매칭·그룹 챌린지 | 사용자 2,000+ · 4.8★ |
| InOut(인아웃) | 식단 AI + 체성분 + 커뮤니티 + AI코치 | 4.9★ · 리뷰 5.4만 |
| 필라이즈(Pillyze) | 식단 + 영양제 AI + 연속혈당(CGM) | 운영 중(국내) · 규모 비공개 |
| 밀리그램(Mealligram) | 식단·눈바디 기록 + 그룹 커뮤니티 | 국내 식단기록 1위 · 170만 DL · 100만+ 사용자 |

### 1.3 시사점
- AI 영상 자세분석은 이미 상용 소비자 앱으로 보편화(Gym Score AI·Gymaholic) → 기술 자체는 차별 요소가 아니다.
- 각 군 선두는 백만 단위 사용자·전용 DB를 보유 → 단일 기능의 정확도/규모 경쟁은 불리하다.
- 다만 여러 기능을 폭넓게 통합한 사례는 제한적이어서, **통합도가 경쟁의 빈 공간**이다.

## 2. 기술 분석

### 2.1 핵심 요소 기술
| 단계 | 기술 | 역할 | 성숙도/공개성 |
|---|---|---|---|
| 객체 검출 | YOLO(v5/v8) | 영상에서 사람·바 영역 크롭 | 오픈소스, 보편화 |
| 자세 추정 | MediaPipe Pose / BlazePose (PoseNet·ConvNeXt 계열도 사용) | 33개 관절 키포인트 추출 | 오픈소스(Apache-2.0), 사실상 표준 |
| 자세 판정 | Random Forest(.pkl) / 관절 각도 규칙 / CNN | 정상·오류 분류·점수화 | 표 형식 특징에 RF 효율적, 규칙 기반 병행 |
| 음식 인식 | EfficientNet-B0 | 음식 이미지 분류 → 영양 매칭 | 오픈 사전학습 모델 |
| 코칭 생성 | 로컬 LLM(Ollama gemma3:4b) | 자연어 코멘트 생성 | 오픈 가중치, 로컬 구동 |

### 2.2 기술적 접근 방식
- 자세 분석은 크게 ① 학습 모델(분류기), ② 생체역학 규칙(관절 각도·상태머신)의 두 갈래로 구현된다.
- 본 프로젝트는 빅3(스쿼트·벤치·데드)는 학습 RF 모델, 추가 운동은 각도 규칙을 쓰는 하이브리드 방식이며, 결과를 5축 점수로 환산한다.
- 기반은 PSLeon24의 오픈소스 `AI_Exercise_Pose_Feedback`(IEEE Access 2024, YOLOv5+MediaPipe+RF)를 참고·확장하였다.

### 2.3 기술 동향
- 포즈 추정 정확도 향상(스쿼트·런지 등 90~96%대 보고), AR 오버레이·실시간 피드백, 3D 포즈 추정으로 확대.
- 핵심 라이브러리(YOLO·MediaPipe)가 오픈소스여서 진입장벽이 낮고, 차별화는 "무엇을 어떻게 점수화/통합하느냐"의 응용 레이어로 이동하고 있다.

## 3. 특허 분석

> 본 항목은 대표 사례 서베이이며, 정밀 특허조사(FTO)가 아니다.
> 정식 출원·상업화 시 KIPRIS·Google Patents 정밀 검색 + 변리사 자문이 필요하다.

### 3.1 관련 특허 동향 (대표 사례)
| 구분 | 특허/사례 | 내용 |
|---|---|---|
| 국내 | KR101819730B1 — 3차원 객체 검출 및 자세추정 방법 | 포인트 클라우드 기반 객체/자세 추정 |
| 국내 | 웨어러블 기기를 이용한 인공지능 자세교정 운동추천 시스템(공개 사례) | 360도 센싱 + 빅데이터 AI로 맞춤 교정운동 추천 |
| 국외(US) | US 12318661 — Exercise guidance using multi-modal data | 멀티모달 데이터 기반 운동 가이드 |
| 국외(US) | US 12364905 — Synthesis of exercise guidance training data | 운동 가이드 학습 데이터 합성 |
| 국외(US) | US 11282214 — Motion matching analysis | 동작 매칭 분석 |
| 인접영역 | 필라이즈 'Panakeia'(영양제 분석 특허 주장) | 건강 데이터·영양제 함량 분석 |

> ※ US 특허번호는 검색으로 수집한 대표 사례로, 정식 인용 전 번호·권리범위 재확인 필요.

### 3.2 특허 관점 시사점
- 핵심 요소 기술(YOLO·MediaPipe·EfficientNet)은 오픈소스 라이선스로 제공되어, 라이브러리 사용 자체는 일반적이고 권리 충돌 소지가 낮다.
- 특허는 주로 "특정 시스템 구성·방법·UX·데이터 생성" 단위로 존재한다 → 동일 기술이라도 구현 방식·청구항이 다르면 회피 가능.
- 본 프로젝트는 비상업 학습/포트폴리오 프로젝트이며, 공개 연구·오픈소스를 출처 명시 하에 참고·확장한 형태라 즉각적 권리 이슈 가능성은 낮다.
- 단, 상업화 전환 시에는 ① "운동 가이드/자세분석" 류 특허에 대한 FTO 검토, ② 오픈소스 라이선스(특히 모델 가중치) 준수 점검이 필요하다.

### 3.3 차별화·권리화 여지
- 응용 레이어인 "5축 점수화 + 운동·식단·체성분·저널 통합 UX"는 단순 포즈 추정과 구분되는 영역으로, 서비스 구성/방법 차원의 차별화 포인트가 될 수 있다. (권리화 가능성은 별도 검토 대상)
