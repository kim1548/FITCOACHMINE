# FitCoach — 시장 조사 및 구현 기능 보고서

> 운동 프로그램 · AI 자세 분석(Form Check) · 식단 · 체성분 · 커뮤니티 통합 헬스 코칭 웹/PWA.
> 본 보고서는 ① 현재 시장의 유사 제품 현황과 ② 본 프로젝트가 실제 구현한 기능을 상세히 정리한다.

## 1.2 제품별 상세 현황

### ① AI 영상 자세분석(폼체크)
- **Gym Score AI** — 운동 영상을 실시간 촬영하거나 업로드하면 AI가 가동범위·자세·코어 안정성·움직임 패턴 등 **5개 카테고리로 분석해 0~100점(GymScore)** 을 부여한다. 2,500여 종 운동을 지원하며 점수 추이 그래프·24/7 AI 코칭 챗·글로벌 랭킹을 제공한다. 무료로 시작 가능, 평점 4.8.
- **Gymaholic AI Form Checker** — 운동 영상을 업로드하면 **전체 폼·제어력·가동범위·템포·정렬·대칭성의 6개 범주 점수**로 평가한다. 스쿼트·데드리프트·벤치·오버헤드프레스·로우·풀업·런지 등 1,800+종 지원. 웹·iOS·Android, 월 $5.25 구독(7일 무료), 사용자 8만+ 규모의 종합 피트니스 앱 'Gymaholic'의 일부.

### ② 중량(바벨) 프로그램 트래커
- **Boostcamp** — StrongLifts·nSuns·5/3/1 등 검증된 프로그램을 **자동 증량 로직과 함께 무료 제공**한다. 볼륨·예상 1RM·PR 추적, 휴식 타이머, AI 프로그램 빌더, 폼 시연 영상 포함. 사용자 120만+, 운동 로그 1.2억+, 프로그램 1.1만+, 평점 4.8(2만+).

### ③ 운동+식단 올인원(AI 코치)
- **GymStreak** — AI 운동 루틴 생성·실시간 조정, AI 식단 사진 인식(매크로/칼로리), 3D 운동 시연, 체지방 계산, 애플워치 연동. 다운로드 400만+, 평점 4.7.
- **MyFitnessCoach** — 식단 사진 AI 인식, 전문 트레이너 운동 프로그램, 체중·신체 지표 추적을 표방. 웹/플레이스토어 존재하나 사용자 규모는 비공개.
- **HealthMatch(헬스매치)** — AI 음식 스캔, 웨어러블 자동 운동 감지, 6,600+운동·3,000+음식 DB, AI 코치 4종(성격), **운동 버디 매칭·그룹 챌린지** 커뮤니티. iOS/Android, 사용자 2,000+, 평점 4.8.

### ④ 식단·체성분·커뮤니티(국내 시장)
- **InOut(인아웃)** — 식단 AI 사진 인식(음식 DB 50만), 체중·신체 기록, AI 코치(말랑), 커뮤니티(피드·대나무숲·다이어트 배틀), 간헐적 단식. 평점 4.9, 리뷰 5.4만, 수일 단위 업데이트로 매우 활발.
- **필라이즈(Pillyze)** — AI 식단(사진/채팅) 기록·칼로리/탄단지, **영양제 AI 분석(특허 'Panakeia', 영양제 DB 2~3만)**, **연속혈당(CGM) 관리**, 인바디·삼성/애플헬스 연동, AI 피티쌤 코칭. 식단을 넘어 영양제·혈당까지 확장한 토탈 영양관리 서비스.
- **밀리그램(Mealligram)** — 사진 기반 식단 자동 기록, 체중·운동·눈바디(체형 사진) 기록, 그룹/커뮤니티(오픈·미니 그룹). **국내 식단기록 분야 iOS/Android 동시 1위**, 누적 170만 다운로드·8,000만 기록·100만+ 사용자·평점 4.8(2.5만+).

## 1.3 종합
- AI **영상 자세분석**은 소비자 앱(Gym Score AI·Gymaholic)부터 상용화되어 있으며, **영상→다축 점수화**가 이미 보편적 방식으로 자리 잡았다.
- **중량 프로그램 자동증량**(Boostcamp), **AI 식단 사진 인식**(GymStreak·인아웃·필라이즈), **체성분·눈바디·커뮤니티**(인아웃·밀리그램) 또한 각 분야별로 백만 단위 사용자층을 가진 성숙한 전용 서비스가 존재한다.
- 다만 시장 제품 대부분은 **한두 개 영역에 특화**되어 있으며, 위 기능을 **단일 앱으로 폭넓게 통합한 사례는 제한적**이다.

# 2. 구현 기능 상세

## 2.1 시스템 아키텍처 개요
의존성 충돌 회피·장애 격리를 위해 **4개 프로세스로 분리**된 구조로 구현하였다.

```
[프론트 :5173]  ──/api──▶  [메인 백엔드 :8001 (FastAPI)]
 React/Vite/PWA                  │
                                 ├──HTTP──▶ [영상 분석 사이드카 :8003 (Python 3.10)]  ← 폼체크
                                 └──HTTP──▶ [Ollama :11434 (gemma3:4b)]              ← AI 총평
```
- 폼체크 AI(MediaPipe·scikit-learn)는 Python 3.10 + 특정 버전이 필수라, 메인 백엔드와 의존성이 충돌하므로 **별도 사이드카(.venv310)** 로 격리하고 HTTP로 위임한다.
- DB는 **SQLite(SQLAlchemy ORM)**, 11개 테이블. AI 총평은 **로컬 LLM(Ollama gemma3:4b)** 으로 생성한다.

## 2.2 회원 · 인증
| 항목 | 구현 내용 |
|---|---|
| 기능 | 회원가입 · 로그인/로그아웃 · 프로필(닉네임·아바타) · 회원탈퇴 · 영양 목표 자동계산 |
| 구현 방식 | 회원가입 시 신체정보(성별·나이·키·체중)·라이프스타일·운동경력·빈도·체력수준·목표 입력. 로그인 성공 시 **JWT(HS256, 유효기간 7일)** 발급, 프론트가 `Authorization: Bearer`로 전송. 비밀번호는 **bcrypt 해시**(직접 호출). 탈퇴 시 연관 기록 트랜잭션 일괄 삭제 |
| 영양 계산 | **Mifflin-St Jeor**로 BMR → 활동계수로 TDEE → 목표별 칼로리 가감(감량 −500 / 유지 0 / 벌크 +400) → 단백질 체중×(2.2/1.6/2.0)g, 지방 25%, 탄수 잔여 |
| API | `POST /auth/signup`, `POST /auth/login`, `GET/PATCH/DELETE /user/me` |

## 2.3 운동 프로그램 (Program)
| 항목 | 구현 내용 |
|---|---|
| 기능 | 10종 프로그램 라이브러리 · 세션 수행 · 자동 증량 · 세션 기록 |
| 프로그램 | StrongLifts 5×5 · Madcow · nSuns 5/3/1 · Starting Strength · Greyskull · GZCLP · Wendler 5/3/1 · Texas Method · PPL · PHUL (프론트 `programs.js` 엔진) |
| 구현 방식 | 모든 프로그램을 "세션 → 운동 → 세트" 구조로 통일, 세트 중량 = 기준중량(anchor) × 비율(pct). **AMRAP/세트 완료 기준 자동 증량**(다음 세션 +2.5/+5kg). 휴식 타이머·원판 계산 |
| 기록 | 완료 세션을 로그인 계정에 저장(`session_data` JSON), 저장 직후 그날 저널 AI 코멘트 백그라운드 생성 |
| API | `POST /routine/log`(인증), `GET /routine/plan/{id}`, `GET /routine/stats` |

## 2.4 AI 자세 분석 (Form Check) — 핵심 기능
| 항목 | 구현 내용 |
|---|---|
| 입력 | 운동 **영상 업로드** 또는 **가이드 촬영**(모바일 카메라, MediaRecorder) |
| 분석 파이프라인 | **YOLO 크롭**(사람/바 영역) → **MediaPipe Pose(33 관절)** → 판정 |
| 판정 2종 | ① **빅3(스쿼트·벤치·데드)**: 원작의 **학습된 Random Forest(.pkl)** ② **추가 15종**: **관절 각도 규칙 + 운동별 상태머신** (총 **18종**) |
| 점수화 | **5축 점수**(안정성·가동범위·동작품질·자세·코어) 산출 = `100 − (유의미 오류 유형 수 × 25)`, 정적 운동은 정자세 프레임 비율 |
| 결과물 | 종합 점수·카테고리별 교정 피드백·**오류 프레임 캡처**(문제 부위 빨간 마커), 실시간 진행률 폴링, 운동 종류 검증 게이트(몸통 방향 검사) |
| 기록·노출 | 분석 결과를 로그인 계정에 저장(`formcheck_logs`) → **저널 일별에 운동명+교정 피드백만 노출(중복 문구 1회만)** |
| 실시간 모드 | 프레임 랜드마크 → 모델 서버에 동기 호출 → 즉시 점수/오류 반환 |
| API | `POST /exercise/analyze_video`(영상), `POST /exercise/analyze`(실시간), `GET /exercise/analyze_progress`, `POST /exercise/formcheck/log`(인증 저장) |

| 댓글·좋아요 | **비밀댓글**(작성자·글쓴이만 열람), 좋아요 토글(중복 방지 유니크 제약) |
| 표시 규칙 | 닉네임 미설정 시 아이디 앞 2자 + 마스킹 |
| API | `GET/POST/PATCH/DELETE /community/posts`, `POST /community/posts/{id}/like`, `.../comments` |

## 2.9 AI 코칭 (로컬 LLM)
- **Ollama gemma3:4b** 로컬 모델로 인바디 코멘트·저널 총평·주간 리포트의 **자연어 코칭 멘트**를 생성한다(`http://localhost:11434/api/generate`).
- 데이터 저장 시점에 **백그라운드(BackgroundTasks)** 로 미리 생성, 실패 시 사용자가 수동 재생성 가능.
- 로컬 구동이라 **API 비용 없음·데이터 외부 유출 없음·오프라인 동작**.
