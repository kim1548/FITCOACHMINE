# 데이터베이스 요구사항 분석서 — FitCoach

> .hwp 양식에 붙여넣어 사용하세요. DBMS: **SQLite**(SQLAlchemy ORM). 총 **11개 테이블**.

## 1. 엔티티 도출
| 엔티티 | 설명 |
|---|---|
| 회원(User) | 계정·신체정보·프로필. 모든 기록의 소유자 |
| 운동기록통계(UserRoutineStats) | 운동별 1RM·증량 단계 |
| 루틴기록(RoutineLog) | 프로그램 세션 1회 기록 |
| 폼체크기록(FormCheckLog) | 폼체크(자세분석) 결과 — 회원별 5축 점수·피드백, 저널 노출 |
| 운동분석로그(WorkoutLog) | (레거시·현재 미사용) 초기 실시간 분석용 — 기록 안 됨 |
| 식단기록(DietLog) | 끼니별 음식·매크로 |
| 체성분기록(InBodyLog) | InBody 측정값 + AI 코멘트 |
| 저널(JournalEntry) | 일별 메모 + 주간/일별 AI 총평 |
| 커뮤니티글(CommunityPost) | 운동 메이트 모집 글 |
| 좋아요(CommunityLike) | 글 좋아요 |
| 댓글(CommunityComment) | 글 댓글(비밀댓글) |

## 2. 관계(Relationship)
- **User 1 : N** UserRoutineStats / RoutineLog / DietLog / InBodyLog / JournalEntry / FormCheckLog / CommunityPost / CommunityLike / CommunityComment
- **CommunityPost 1 : N** CommunityLike, CommunityComment (글 삭제 시 CASCADE)
- FormCheckLog: user_id FK 연결, logged_date 로 저널 일별 entry 와 조인
- WorkoutLog는 user_id 미연결 + 현재 미사용(레거시) — 폼체크 결과는 FormCheckLog 에 저장
- JournalEntry: (user_id, entry_date) 사실상 1일 1건 (UniqueConstraint 권장)

## 3. ERD 개요 (텍스트)
```
User ─┬─< UserRoutineStats
      ├─< RoutineLog
      ├─< DietLog
      ├─< InBodyLog
      ├─< JournalEntry
      ├─< FormCheckLog
      └─< CommunityPost ─┬─< CommunityLike
                         └─< CommunityComment
```

## 4. 무결성/제약
- PK: 모든 테이블 `id` (자동 증가)
- FK: 대부분 `user_id → users.id`, 커뮤니티 자식은 `post_id → community_posts.id (ON DELETE CASCADE)`
- UNIQUE: `users.username`
- NOT NULL: `community_posts.body`, `community_comments.body`, `inbody_logs.weight`(체중 필수)
- DEFAULT: 매크로 0.0, is_secret=False, step_weight=2.5, 타임스탬프 자동

## 5. 테이블 요약 (상세는 4_테이블명세서 참고)
| 테이블ID | 테이블명 | 설명 |
|---|---|---|
| users | 회원 | 계정·신체정보·프로필(닉네임/아바타) |
| user_routine_stats | 운동통계 | 운동별 1RM·증량 단계 |

| workout_logs | 운동분석로그 | (레거시·미사용) 초기 실시간 분석용 |
| diet_logs | 식단기록 | 끼니별 음식·매크로 |
| inbody_logs | 체성분기록 | InBody 측정값·AI 코멘트 |
| journal_entries | 저널 | 일별 메모·AI 총평 |
| community_posts | 커뮤니티글 | 운동 메이트 글 |
| community_likes | 좋아요 | 글 좋아요 |
| community_comments | 댓글 | 글 댓글(비밀댓글) |
