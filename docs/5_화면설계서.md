# 화면 설계서 — FitCoach

> .pptx 양식의 "화면 목록·서비스 흐름도·화면별 설계" 슬라이드에 옮겨 사용하세요.
> (각 화면을 한 슬라이드씩 캡처/와이어프레임으로 구성 권장)

## 1. 서비스 흐름도
```
[Landing/비로그인]
   ├─ 회원가입 → 로그인 → [Journal(메인)]
   └─ Sign in  → ────────┘
[Journal(메인)] ─ 상단 네비 ─┬─ Community
                            ├─ Program ── 세션수행 ── 요약
                            ├─ Form Check ── 촬영/업로드 ── AI 진단
                            ├─ Meals ── 식단 추가
                            ├─ Body(InBody)
                            └─ Journal(달력/주간리포트)
[상단 우측] 아바타(드롭다운: 아바타 변경) · Settings(닉네임/알림/Get the app/로그아웃)
[모바일] 하단 탭바로 6개 섹션 이동
```

## 3. 화면별 구성 (주요)

### S-01 랜딩
- 상단: 워드마크(FITCOACH) + 발행호수
- 히어로: "The journal of your active self." + Register/Sign in/Browse as guest
- 하단: 6개 챕터 소개, How it works(3단계), Begin CTA

### S-04 저널(메인)
- 헤드라인 + 이번 주 리포트 카드(운동 횟수·식단일·체중변화) + ✦AI 총평 버튼
- 월 달력(세션 기록 점·오늘 강조), 날짜 클릭 → 일별 entry 모달(운동/식단/체성분/폼체크 교정 피드백/코치노트)
- 우측: This month(세션 수·PR·휴식일), Current streak

### S-05 프로그램 라이브러리
- 부위 필터(가슴/등/하체/어깨/복근/팔)
- Featured 추천 카드(포스터·프로그램명·태그·가이드·Start)
- The full library(컴팩트 리스트), 진행 중 프로그램은 Continue/Reset

### S-09 폼체크 촬영/분석
- 운동 헤드라인(예: "벤치프레스, analyzed.")
- CAPTURE: 가이드 촬영(풀스크린 카메라) / 영상 올리기
- 분석 진행률 → 5축 진단 리포트(안정성·가동범위·동작품질·자세·코어)

### S-10 식단(Meals)
- 끼니별(아침/점심/저녁/간식) 카드, 칼로리·탄단지 합계
- 목표 매크로 대비 진척 바, 음식 추가/즐겨찾기

### S-12 체성분(Body)
- InBody 입력 모달(측정일·체중 필수·골격근/체지방/체지방률/BMR)
- 추이 그래프(Recharts), 항목별 카드, AI 코멘트

### S-13 커뮤니티(Personals)
- 헤드라인 + Write an entry
- 글 카드: 아바타·닉네임·나이·위치·1RM(스쿼트/벤치/데드)·본문·Send a note(댓글)·Save(좋아요)·Edit/Delete

### S-14 설정(Settings, 드로어)
- 닉네임 수정 / 알림(운동·식사 시간 + 테스트) / Get the app(설치 링크·스토어 뱃지) / Account(로그아웃·회원탈퇴)

## 4. 공통 UI
- 상단 마스트헤드: 워드마크 + 섹션 탭(데스크탑) + 아바타·Settings
- 모바일: 하단 탭바(6섹션) + 풀스크린 카메라 + PWA 설치
- 톤: Editorial Magazine(다크 옥스블러드/크림), 반응형(화면폭 비례 스케일)
