# 영양제 추천 시드 데이터

영양제 맞춤 추천 엔진용 기초(seed) 데이터. 앱 첫 실행 시 DB에 적재한다.
설계 근거: `docs/11_영양제추천엔진_설계서.md`, `docs/12_영양제추천_휴리스틱규칙.md`

## 파일

| 파일 | 테이블 | 행 수 | 내용 |
|---|---|---|---|
| `nutrient_rda.csv` | `nutrient_rda` | 22 | 영양소별 권장섭취량·상한섭취량 (연령/성별) |
| `supplement.csv` | `supplement` | 50 | 영양제 제품 마스터 |
| `supplement_ingredient.csv` | `supplement_ingredient` | 81 | 제품 ↔ 성분 함량 매핑 |
| `interaction_rule.csv` | `interaction_rule` | 20 | 상호작용/금기 규칙 (안전 필터용) |

## 영양소 코드 (12종 — 휴리스틱 규칙과 동일)

`VIT_D` 비타민D · `OMEGA3` 오메가3 · `CALCIUM` 칼슘 · `MAGNESIUM` 마그네슘
`IRON` 철분 · `ZINC` 아연 · `VIT_C` 비타민C · `VIT_B` 비타민B군
`PROTEIN` 단백질 · `PROBIOTICS` 유산균 · `LUTEIN` 루테인 · `FOLATE` 엽산

## 데이터 출처 (발표 대응)

- **권장섭취량(`nutrient_rda`)**: 보건복지부·한국영양학회 **「한국인 영양소 섭취기준(KDRIs)」** 의
  RDA(권장섭취량)·UL(상한섭취량) 값을 성인 연령대 기준으로 정리.
- **영양제 제품·함량(`supplement`, `supplement_ingredient`)**: 시중 유통 대표 건강기능식품 유형을
  **식약처 식품안전나라 건강기능식품 정보** 및 제품 표기 일일섭취량 기준으로 큐레이션한 **대표 샘플 50종**.
  특정 브랜드 상표는 제외하고 제품 유형명으로 일반화.
- **상호작용 규칙(`interaction_rule`)**: 널리 알려진 영양제-약물/질환 상호작용 대표 사례를 정리.

> 범위 주: 전체 시장 DB(수만 종)가 아니라 **추천 엔진 동작 검증용 대표 샘플**.
> `supplement` 테이블 구조는 식약처 OpenAPI 연동으로 무한 확장 가능하도록 설계됨(엔진 코드 변경 불필요).

## 주의

- 본 데이터와 추천 결과는 **정보 제공 목적**이며 의학적 진단·처방이 아니다.
  복용 전 전문가 상담 권장(면책 문구는 화면·AI 프롬프트에 명시).
